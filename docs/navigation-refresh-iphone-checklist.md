## בדיקות קצרות

- [ ] **מעברים מהתפריט:** פתחו עריכת פרופיל, הגדרות והתראות. התפריט נסגר לפני שהעמוד נכנס משמאל; הכותרת והתוכן נעים יחד, בלי הבהוב או קפיצה. חזרו בכפתור ובמחווה ובדקו שהתפריט לא נפתח מחדש.
- [ ] **עמודים פנימיים:** מהגדרות פתחו שינוי שם/סיסמה; מהתראות פתחו הגדרות התראות. בדקו כניסה וחזרה אחידות. אין צורך לשמור שינויי חשבון לצורך הבדיקה.
- [ ] **מחווה שנקטעת:** התחילו חזרה מקצה ימין ועצרו באמצע, ואז שחררו כך שהחזרה תתבטל. הכותרת והתוכן חוזרים יחד למקומם. נסו גם מחווה שמושלמת.
- [ ] **שינויים שלא נשמרו:** בעריכת פרופיל שנו העדפה בלי לשמור. בדקו כפתור חזרה ומחוות חזרה: ביטול בחלונית משאיר את העריכה, ואישור יציאה מחזיר לפרופיל. מחווה מבוטלת לא מאבדת עריכות.
- [ ] **לחיצות מהירות ותמיכה:** לחצו פעמיים במהירות על פריט בתפריט — נפתח עמוד אחד בלבד. עזרה ותמיכה מופיעה כחלונית אחרי סגירת התפריט.
- [ ] **מונה ההתראות החדש:** בטאב פרופיל מופיע מספר ההתראות שלא נקראו. פתחו את ההתראות דרך תפריט הפרופיל, קראו התראה וחזרו לסרגל — המונה קטן. כשכולן נקראו, התג נעלם. מעל 99 מוצג 99+; אין חפיפה לכיתוב גם בטקסט מוגדל.
- [ ] **תמונת הפרופיל בבית:** התמונה ממלאת את העיגול בלי סטייה הצידה או חיתוך של המסגרת. לחיצה עליה עדיין פותחת את הפרופיל.
- [ ] **סרגל תחתון:** מימין לשמאל בית, קהילה, פלוס, מועדפים, פרופיל. הפלוס בתוך הסרגל; אין כפתורי הוספה צפים בפידים. באורח מופיעה התחברות במקום פרופיל.
- [ ] **נראות:** חמישה מקומות שווים, אייקונים וטקסט ללא חפיפה. התוכן נראה מתחת לסרגל ובאזור פס הבית של iPhone; אין פס כחול נוסף. בדקו גם עם גודל טקסט מוגדל.
- [ ] **פלוס:** פתחו מכל אחד מהטאבים, סגרו ב־X וגם בלחיצה על הרקע. חוזרים בדיוק לאותו טאב ולמיקום הגלילה הקודם.
- [ ] **יצירה:** ״פרסום המלצה״ ו״פרסום מסלול״ פותחים את העורכים המתאימים. חזרה מהם עובדת גם במחוות החזרה. אין צורך לפרסם תוכן ניסוי ציבורי. ״תכנון טיול״ מסומן ״בקרוב״ ואינו פותח את עורך המסלול הציבורי.
- [ ] **קהילה:** בצעו חיפוש, סינון, מיון וגלילה בהמלצות; עברו למסלולים ובחרו חיפוש/סינון שונים. חזרו להמלצות — המצב הקודם נשמר. חזרו למסלולים — המצב שלו נשמר בנפרד.
- [ ] **מפה וטאבים:** פתחו את מפת ההמלצות והזיזו אותה. עברו למסלולים וחזרה — מצב המפה נשמר. עברו לבית וחזרה לקהילה — חוזרים לתצוגה האחרונה שנבחרה. לחיצה נוספת על קהילה גוללת את הרשימה הפעילה למעלה, ובחלק העליון מרעננת.
- [ ] **התראות:** פרופיל → תפריט → התראות. התראות נפתחות מעל המסך, ללא הסרגל התחתון; חזרה מחזירה לפרופיל. המונה בתפריט מתעדכן. אם מתקבלת התראת פוש אמיתית, פתיחתה מובילה להתראות ולתוכן המתאים.
- [ ] **אורח ומקלדת:** בפתיחת פרסום כאורח מופיעה בקשת התחברות. ״לא עכשיו״ מחזיר למסך שממנו התחלתם. בזמן הקלדה הסרגל מוסתר וחוזר עם סגירת המקלדת; החיפוש אינו נמחק.
- [ ] **קישורים קיימים:** ״לכל המסלולים״ בבית פותח קהילה במצב מסלולים. ״הצגה במפה״ מתוך המלצה פותחת את מפת ההמלצות על הנקודה הנבחרת.
- [ ] **הסיור של נועה, אם מוצג:** המעבר למסלולים מתרחש בתוך הקהילה. ההסבר על הוספה מצביע על הפלוס שבסרגל.

במקרה של תקלה, ציינו את הטאב, הפעולה, המצב לפני ואחרי, והאם הייתם מחוברים. צילום מסך או סרטון קצר יעזרו לשחזור.
